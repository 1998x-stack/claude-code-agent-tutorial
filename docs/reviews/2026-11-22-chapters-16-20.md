## 真实性与工程边界

1. 所有 Python 代码为可测试的离线教学模型。PermissionGateway 不产生 UI 真实签名，SandboxManifest 不执行 Shell/系统调用，也不代替真实 OS 防护。
2. MCP 协议范例不建立网络连接、不启动外部 Server；真实互通应采用兼容 2026 与 legacy 的 SDK 进行端到端测试。
3. ContextTuning 的 token 数是明确标注的假设数据；API usage、延迟、模型质量和成本均需独立采样。
4. 仍待精修 21–28 章；首页状态只代表已覆盖的 01–20 章。

## 边界与验收

- Python 用例是有界、无密钥、离线教学模拟。不保证安全抗文件系统竞态、不是真实 Claude Code 的内核级执行环境。
- long-running FeatureLedger 的 actor 字符串只作说明；真实人类或评估器身份必须由可信外部系统核实。
- kill switch 标记本身不能中断已发出的外部进程和请求。
- live Messages 模式只在用户选择时调用本地安装的 SDK，CI 不调用外部 API，不使用/存储 API Key。
- 本批 SVG 6 幅；所有独立 SVG 有 title、desc、viewBox，页面包含图注和可滚动移动端视图。
- `python3 tools/validate_site.py`：规范的 28 章静态 H1、链接、SVG 和图片属性。
- `python3 -m unittest discover -s examples -p 'test_*.py'`：所有既有与新离线测试。
- `python3 tools/browser_qa.py --output qa-output`：首页 + 28 章，在 1440/768/390/360 px 上共 116 项浏览器视口，保留截图和 JSON 报告。
- 原始 26–28 章归档在 `archive/initial`；首页、课程元数据、README 和 AGENTS 同步更新。
- GitHub Pages 只在合并后且成功部署后才可称发布完成。
